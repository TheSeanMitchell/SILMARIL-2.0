# 02 · PHILOSOPHY — why the machine is built to refuse to lie

**One objective (4.0, still canon):** make it impossible for the engine to lie — statistically.
Profit is a consequence; truth first. 5.x adds: prove the edge, then prove it TRAVELS, and never
spend a feature where evidence hasn't paid for it.

## The Laws, condensed (1–16; full history in attic backbones)
1–8 (3.0/4.0): determinism · auditability · fee-honesty (2× friction) · walk-forward-only promotion ·
luck baselines · append-only long memory · no synthetic data · champion by forward evidence.
9 **Provenance** — every governing artifact carries `evidence_basis`; provisional never displayed as proven.
10 **Null Twin** — every book judged Δ-vs-null (CASH/SPY/HODL/EQW). Beating zero is not beating anything.
11 **Admission** — markets via M0–M5, families via F0–F4. Enthusiasm has no rung.
12 **Contracts** — schema per store; producer→consumer registry; failure is a RED light, not a silent starve.
13 **Cost truth per venue** — each venue's own measured round-trip; never crypto's number elsewhere.
14 **Attention budget** — API calls/runner minutes/bytes are allocated resources.
15 **Pre-registered death** — every experiment declares its kill criterion before logging starts.
16 **Utilization measured** — idle capital is priced; armed-never-deployed is a finding.

## Gates doctrine
Nothing unproven touches a decision. Every gate: OBSERVE → (evidence ≥ need AND its stated proof
holds) → WEIGHTED. 5.1's `gate_evidence` makes the counts REAL tallies from named stores. The one
operator-directed exception with teeth: `heatshield_autotune` — the floor resolver applies the
MEASURED winner (n≥60, clamped 4–10%, reversible knob) and the gate reads WEIGHTED only while
genuinely applied.

## Honesty rules that bind every surface
Realized P&L only · gross vs net always labeled (the PYTH/STRK lesson) · dollars always beside the
WAGER (the THETA $1.62 lesson: +3.7% on $48) · a green day proves nothing (the GEKKO-bug +HODL
lesson: nobody beat holding that Thursday) · "insufficient evidence" is a valid, honest display
state · one honesty caveat per report, then work.

## The unlock
**100 out-of-sample trades surviving the gate across 90 unbroken days.** No header, milestone, or
enthusiasm opens that door. Evidence does.
